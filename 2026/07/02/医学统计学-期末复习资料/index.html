一、统计描述

统计描述 = 用指标、图表来描述数据的特征。分为计量资料和计数/等级资料两大分支。

1.1 计量资料的统计描述

计量资料（定量数据）的描述包含两个维度：集中趋势（数据聚集的中心位置）和离散趋势（数据的分散程度）。

1.1.1 集中趋势的指标

指标适用条件说明
算术均数（X̄）正态分布资料最常用，对称分布首选
几何均数（G）对数正态分布 / 成倍数变化资料（如抗体滴度）实验室中抗体滴度资料必须用几何均数
中位数（M）偏态分布资料；末端无确切值；分布类型不明不受极端值影响

【重点·录音强调】

  • 正态计量资料 → 用 X̄ ± S（均值 ± 标准差）描述
  • 偏态资料 → 用 M（P₂₅, P₇₅） 描述，即中位数 + 四分位数
  • 几何均数比较少用，主要用于抗体滴度等成倍数变化的资料

【选择题常见考法】：给一组数据让你判断该用什么指标。如 1, 2, 3, 4, 100：

  • 有一个极端值 100，数据呈偏态 → 应算中位数 = 3.5
  • 如果数据是 1, 2, 3, 4, 5（对称）→ 应算均数 = 3

【教材校准】 教材中集中趋势指标还包含众数，但录音中老师未强调众数，考试权重较低。

1.1.2 离散趋势的指标

指标公式/含义适用条件与注意
极差（R）R = Xmax − Xmin粗略，仅反映两端差异
四分位数间距（IQR）IQR = P₇₅ − P₂₅偏态资料的首选离散指标
方差（S²）S² = Σ(X − X̄)² / (n − 1)标准差的平方，不太常用
标准差（S）S = √(方差)正态资料的首选离散指标
变异系数（CV）CV = S / X̄ × 100%特殊场景使用（见下）

【重点·变异系数 CV 的适用条件】（录音反复强调）

CV 适用于以下两种情况的变异程度比较：

  1. 均数相差较大的两组或多组数据（如成人体重均值 vs 婴幼儿体重均值）
  2. 单位不同的指标（如比较身高和体重的变异哪个大）

为什么不能用标准差直接比？因为均数相差大或单位不同时，标准差本身不可比，需要用 CV 消除量纲和均数影响。

1.1.3 录音重点回顾：集中趋势指标的选择题转化

以前出简答题「描述集中趋势的常用指标及各自适用范围」，今年改为选择题，形式如：

  • 给一组数据，判断该用均数还是中位数
  • 核心原则：看到极端值/偏态 → 中位数；对称/正态 → 均数

1.2 正态分布与医学参考值范围

1.2.1 正态分布的特征

正态分布有两个参数：

参数符号作用
位置参数μ（总体均数）决定曲线在 X 轴上的位置，μ 越大曲线越靠右
形状参数σ（总体标准差）决定曲线的”胖瘦”，σ 越大曲线越扁平

【教材校准】录音中老师将 σ 称为”形态参数”，教材中标准术语为”形状参数”，含义一致。

1.2.2 正态曲线下面积规律（送分题必考）

区间面积（概率）记忆口诀
μ ± 1σ68.27%—
μ ± 1.96σ95%最常用
μ ± 2.58σ99%—

【高频考题】 μ 到 μ + 1.96σ 对应的面积 = 47.5%（95% 的一半，不是 95%！）

1.2.3 标准正态分布

  • 标准正态分布：μ = 0，σ = 1
  • z 变换公式：z = (X − μ) / σ （将任意正态分布转换为标准正态分布）
  • 查 z 界值表即可得到对应的概率

1.2.4 医学参考值范围

【核心考点】 两种计算方法及适用条件：

方法适用条件公式（双侧95%）统计量
正态分布法正态分布资料X̄ ± 1.96S均数 + 标准差
百分位数法偏态分布资料P₂.₅ ~ P₉₇.₅（双侧）百分位数

【单侧/双侧选择】

指标类型取值方向所用方法界值
过高异常（如发铅、血压）单侧上限百分位数法P₉₅
过低异常（如肺活量）单侧下限百分位数法P₅
过高过低均异常（如白细胞数）双侧正态分布法或百分位数法—

【录音举例】

  • 发铅：偏态分布，过高算异常 → 百分位数法，单侧上限，取 P₉₅
  • 12 岁男童身高：正态分布 → 正态分布法，X̄ ± 1.96S

【教材校准】

  • 教材中正态分布法双侧 95% 的公式为 X̄ ± 1.96S，录音中老师表述为”S拔加减 1.96 乘以 S”，应为 “X̄ ± 1.96S”（样本均数加减 1.96 倍样本标准差）。
  • 教材中明确：百分位数法双侧 95% 参考值范围为 P₂.₅ ~ P₉₇.₅。

1.3 计数资料与等级资料的统计描述

1.3.1 常用相对数

类型定义公式例子
率（rate）某现象实际发生数 / 可能发生该现象的总数率 = 发生数 / 总观察数 × 比例基数发病率、死亡率、治愈率
构成比（proportion）部分 / 全体构成比 = 某一组成部分的观察单位数 / 同一事物各组成部分观察单位总数 × 100%男性占患病总人数的比例
相对比（ratio）A / B相对比 = A指标 / B指标性别比、比值比

1.3.2 率和构成比的区别（高频易错点）

率构成比
含义反映某现象发生的频率或强度反映某部分在总体中所占比重
分母可能发生该现象的总观察单位数同一事物各组成部分的总和
数值范围可为任意正数0~100%（总和为100%）

【录音经典例题】

总共 500 人患病，男性 400 人，女性 100 人。问男性是否更容易患病？

  • 分析：只知道患病者中男性占 400/500 = 80%，这只是构成比，不是率！
  • 要知道率，还需要知道总人群中男女各多少人（分母）。
  • 因此不能得出”男性更易患病”的结论。

1.3.3 相对数使用注意事项（教材 5 条）

  1. 计算相对数时分母不宜过小（样本量太小时用绝对数表示）
  2. 不能以构成比代替率（最重要的一条）
  3. 正确计算平均率（不能直接对几个率求平均）
  4. 注意资料的可比性——当内部构成不同影响总率时，需率的标准化
  5. 样本率或构成比的比较应做假设检验

1.3.4 率的标准化

  • 为什么要标准化：当两组或多组资料的内部构成（如年龄构成）不同，直接比较总率会产生偏倚
  • 怎么做：选择一个标准构成，统一各组内部构成后计算标准化率
  • 标准构成的选取方法：
    • 任选一组数据作为标准
    • 将各组数据合并作为标准
    • 选用通用的标准（如全国人口普查年龄构成）

1.4 统计表与统计图

1.4.1 统计表的核心规则——三线表

【绝对重点】 统计表必须是三线表：

  • 顶线（最上方粗线）
  • 底线（最下方粗线）
  • 分隔线（表头与表体之间的细线，仅一条）

不允许有竖线、斜线、多余的横线。仅三条线！

【卡方检验四格表的格式陷阱】

  • 卡方检验中需要画四格表，四格表也必须是三线表形式
  • 不能画成带竖线的表格（很多同学画错）
  • 教材上的四格表都是三线表格式

1.4.2 统计图的选用

图形类型适用数据说明
直方图连续型定量数据（频数分布）无间隔的矩形条
箱式图定量数据分布特征显示 M, P₂₅, P₇₅, 极值
散点图两变量关系相关/回归分析前必画
线图随时间变化的趋势连续变化
直条图相互独立的组间比较有间隔
圆图/百分条图构成比各部分占整体的比例

二、统计推断

统计推断 = 用样本信息推断总体特征。分为参数估计和假设检验两大方法。

2.1 参数估计

2.1.1 两种方法

方法内容优缺点
点估计用样本统计量直接作为总体参数的估计值简单，但无精度信息
区间估计给出一个区间范围（置信区间），以一定置信度（如95%）包含总体参数重点，提供估计精度

2.1.2 置信区间（可信区间）

【核心概念·必考】

  • 95% 置信区间的含义：该区间包含总体均数的可能性是 95%
  • ❌ 不能说”总体均数落在该区间的可能性是 95%”
    • 总体均数是固定值（非随机变量），不是它”落”入区间，而是区间”包含”总体均数

【通用公式】 所有置信区间 = 统计量 ± 界值 × 标准误

场景公式
总体均数（σ 未知）X̄ ± t(α/2, ν) × S_X̄，其中 S_X̄ = S / √n
总体均数（σ 已知 / 大样本）X̄ ± z(α/2) × σ_X̄
总体率p ± z(α/2) × S_p，其中 S_p = √[p(1−p)/n]
两均数之差(X̄₁ − X̄₂) ± t(α/2, ν) × S_{X̄₁−X̄₂}

2.1.3 置信区间 vs 医学参考值范围（高频易混淆）

置信区间医学参考值范围
目的估计总体参数（如总体均数）描述个体值的分布范围
对象统计量（均数、率）个体观察值
公式X̄ ± t × S_X̄（用标准误）X̄ ± 1.96S（用标准差）
共同点都是一个区间范围—

【录音强调】以前出简答题”可信区间和参考值范围的区别和联系”，唯一联系就是”都是区间”，其他全是区别。换选择题形式就是给你公式让判断是算置信区间还是参考值范围——关键在于用的是标准误（S_X̄）还是标准差（S）。

2.2 假设检验基础

2.2.1 基本步骤

  1. 建立检验假设，确定检验水准 α
    • H₀（原假设/零假设）：通常是”无差异”假设
    • H₁（备择假设）：与 H₀ 对立
    • α = 0.05（常用）
  2. 选择检验方法，计算检验统计量
  3. 确定 P 值，作出推断结论
    • P ≤ α → 拒绝 H₀，差异有统计学意义
    • P > α → 不拒绝 H₀

2.2.2 两类错误

错误类型定义概率符号关系
第Ⅰ类错误H₀ 为真却被拒绝（”假阳性”）α增大 α 会减少 β，反之亦然
第Ⅱ类错误H₀ 为假却不拒绝（”假阴性”）β—
  • 检验效能（Power） = 1 − β，即 H₀ 为假时正确拒绝它的概率
  • 增大样本量可同时减少两类错误

2.2.3 P 值的正确理解

  • P 值是在 H₀ 成立条件下，观察到当前及更极端结果的概率
  • P < 0.05 表示”差异具有统计学意义”，不代表差异的实际大小
  • P 值越小，越有理由拒绝 H₀

2.3 t 检验（计量资料·正态·两组）

2.3.1 三种 t 检验

类型适用设计条件检验统计量
单样本 t 检验一个样本均数与已知总体均数 μ₀ 比较样本来自正态总体t = (X̄ − μ₀) / (S/√n)
配对 t 检验配对设计（同体配对/异体配对）差值 d 服从正态分布t = d̄ / (S_d / √n)
独立样本 t 检验完全随机设计两样本比较两总体均正态 + 方差齐t = (X̄₁−X̄₂) / S_{X̄₁−X̄₂}

2.3.2 配对设计 vs 完全随机设计（判断关键）

配对设计完全随机设计
同体配对：治疗前后、左臂右臂、耳垂血手指血随机分成两组，各自接受不同处理
异体配对：按性别相同、年龄相近、体重相近**”配成对子”**—

【录音判断技巧】题干有”配成对子”字样 → 配对设计；否则 → 完全随机设计。题库中异体配对很少，基本是同体配对（治疗前后等）。

2.3.3 方差齐性检验与 t’ 检验

  • F 检验（方差齐性检验）：H₀ 为两总体方差相等，F = S₁² / S₂²（大/小），检验水准 α = 0.10
  • 方差不齐 → 使用 t’ 检验（近似 t 检验，Satterthwaite 法校正自由度或 Cochran & Cox 法校正界值）

2.3.4 应用条件总结

  • t 检验的前提：① 正态性；② 方差齐性（配对 t 检验不需要方差齐性假定）
  • 不满足条件 → 变量变换或改用秩和检验
  • 大样本情况下可用 z 检验替代

【教材校准】录音中提到”参数检验条件”即正态分布 + 方差齐。配对 t 检验只需差值满足正态，不需要两组各自正态和方差齐。

2.4 方差分析（计量资料·正态·多组）

2.4.1 基本思想

  • 用途：**多组（k ≥ 3）**均数比较，不能用多次 t 检验（会增大Ⅰ类错误）
  • 核心：总变异 = 组间变异 + 组内变异
    • SS_总 = SS_组间 + SS_组内
    • ν_总 = ν_组间 + ν_组内（ν_总 = N−1，ν_组间 = k−1，ν_组内 = N−k）
  • 检验统计量：F = MS_组间 / MS_组内
  • 如果 H₀ 成立（各组均数相等），F 值理论上接近 1

2.4.2 两种设计

设计类型变异分解适用
完全随机设计（单因素）SS_总 = SS_组间 + SS_组内一个处理因素，多个水平
随机区组设计（配伍组）SS_总 = SS_处理 + SS_区组 + SS_误差两个因素，其中一个为区组因素

【教材校准】录音中老师提到”配伍组方差分析”即随机区组设计方差分析，它属于两因素方差分析，不是单因素。

2.4.3 方差分析的 H₁

  • H₀：μ₁ = μ₂ = … = μ_k（各组总体均数全相等）
  • H₁：各组总体均数不全相等（或至少有两组不等）
  • ❌ 不能说 H₁ 是”各组都不相同”！

2.4.4 方差分析显著后的两两比较

  • 方差分析拒绝 H₀ 后，需要做多重比较才知道具体哪两组不同
  • 不能用普通 t 检验直接两两比较（增加Ⅰ类错误）
  • 常用方法：SNK-q 检验、LSD-t 检验、Bonferroni 法等

2.4.5 考试定位

【录音明确】方差分析不考大的计算题（计算量太大），但选择题必考。考点包括：基本思想、H₁ 的写法、自由度的计算、F 值的含义等。

2.5 非参数秩和检验（计量资料·偏态 / 等级资料）

2.5.1 什么时候用秩和检验？

  • 总体分布类型未知或非正态
  • 有序/等级资料
  • 数据两端无确定数值（如 >100、<0.01）
  • 方差不齐且变换无效

优点：适用范围广，不依赖分布假设
缺点：仅利用秩次信息，检验效能低于参数检验。满足参数条件时应首选参数检验。

2.5.2 秩和检验与 t 检验/方差分析的对应关系

场景满足正态不满足正态
配对设计配对 t 检验Wilcoxon 符号秩和检验（检验统计量 T）
两组独立独立样本 t 检验Wilcoxon 秩和检验（检验统计量 T，取较小样本秩和）
多组独立单因素方差分析Kruskal-Wallis H 检验（检验统计量 H，近似 χ² 分布）

2.5.3 Kruskal-Wallis H 检验

  • 用于多组独立样本（不满足方差分析条件时）
  • 检验统计量写 H（老师强调论文中也要写 H，不是 χ²）
  • H 近似服从自由度为 k−1 的 χ² 分布（k 为组数）
  • H₀：各组总体分布相同（或分布位置相同）

2.5.4 等级资料的假设检验

【核心原则】 等级资料（如疗效分为痊愈/显效/有效/无效）：

  • 比较疗效等级 → 用秩和检验（不能用卡方检验！）
  • 比较治愈率（二分类）→ 用卡方检验

【教材校准】录音中老师举例：”疗效分为无效、显效、治愈，两组比较疗效 → 秩和检验；比较治愈率 → 卡方检验”。这与教材 R×C 表注意事项第 3 条一致。

【录音陷阱提醒】 有同学在开题报告中用卡方检验处理等级资料，老师指出这是错的——等级资料有顺序，卡方检验会丢失顺序信息。

2.6 卡方检验（计数资料）

2.6.1 四格表卡方检验

  • 用于两样本率的比较
  • 基本公式：χ² = Σ[(A − T)² / T]，ν = 1
  • 专用公式：χ² = (ad − bc)² × n / [(a+b)(c+d)(a+c)(b+d)]

四格表基本形式：

组别阳性阴性合计
A 组aba+b
B 组cdc+d
合计a+cb+dn

2.6.2 校正条件（必须记住！）

条件所用方法
n ≥ 40 且所有 T ≥ 5不用校正（基本公式/专用公式）
n ≥ 40 但有 1 ≤ T < 5校正公式（Yates 连续性校正）
n < 40 或 T < 1Fisher 确切概率法

【教材校准】校正公式为 χ² = Σ[(|A−T| − 0.5)² / T] 或 χ² = (|ad−bc| − n/2)² × n / [(a+b)(c+d)(a+c)(b+d)]。录音中老师说”分子上减了点东西就是校正的，减 2 分之 n”即指 n/2 的连续性校正。

2.6.3 配对四格表卡方检验（McNemar 检验）

  • 用于配对设计的计数资料（如同一样本用两种方法检测）
  • 公式：χ² = (b − c)² / (b + c)，ν = 1（b+c ≥ 40 不用校正）
  • 校正：χ² = (|b−c| − 1)² / (b + c)（b+c < 40 需校正）
  • 只考虑不一致的对子（b 和 c）

2.6.4 R×C 列联表卡方检验

  • 用于多个样本率或多个构成比的比较
  • 公式：χ² = n × [Σ(A²/(nR×nC)) − 1]
  • 自由度：ν = (R−1) × (C−1)（高频送分题！）

【例题】 三组率的比较（3 行 × 2 列）：

  • ν = (3−1) × (2−1) = 2

2.6.5 R×C 表注意事项

  1. 理论频数不宜小于 1，且 1 ≤ T < 5 的格子数不超过总格子数的 1/5
  2. 多组率比较拒绝 H₀ 后，需做多重比较（χ² 分割法 + Bonferroni 校正 α’）
  3. 有序分类资料（如疗效等级）不宜用 χ² 检验，应用秩和检验
  4. R×C 表 χ² 检验与分类结果的排序无关

2.6.6 常见陷阱：四格表合计列混淆

【录音重要提醒】

考试时老师可能不给阴性例数，只给合计和阳性例数，你需要自己算出阴性例数。很多同学直接把合计当 B 代入公式算，全错了！

示例：老师给的是以下格式——

组别阳性合计
A 组aa+b
B 组cc+d

你需要自己：b = (a+b) − a，d = (c+d) − c，再代入四格表公式。

2.7 线性回归与相关

【考试定位】不考大的计算题，但选择题必考。

2.7.1 线性回归

  • 回归方程：Ŷ = a + bX
    • b：回归系数，表示 X 每变化一个单位，Y 平均变化 b 个单位
    • a：截距（常数项）
  • 参数估计方法：最小二乘法（使 Σ(Y−Ŷ)² 最小）
  • 假设检验：H₀: β = 0（方差分析或 t 检验，两者等价：F = t²）

2.7.2 线性相关

  • 相关系数 r：衡量两变量线性相关方向和密切程度
    • −1 ≤ r ≤ 1，|r| 越近 1 相关越密切
    • r > 0 正相关，r < 0 负相关，r = 0 无线性相关
  • 条件：两变量服从双变量正态分布
  • 假设检验：H₀: ρ = 0（t 检验或查 r 界值表）
  • 决定系数 R² = r²：回归平方和在总平方和中的占比

2.7.3 相关与回归的区别和联系（高频考点）

【两个区别】

直线相关直线回归
资料要求双变量正态分布（X 和 Y 都正态）Y 正态即可（X 可以是给定的）
方向性双向，不分主次单向，Y 依赖于 X
X 的选择—原因变量 / 变异小的 / 易获得的作为 X

【三个联系】

  1. r 和 b 的符号必须一致：r > 0 ⇒ b > 0，r < 0 ⇒ b < 0
  2. r 和 b 的假设检验等价（对同一资料，t_b = t_r）
  3. b = r × (S_Y / S_X)，R² = r² = SS_回归 / SS_总

【录音强调】”r > 0 时 b 一定 > 0，如果选项说 r > 0 且 b < 0，那就是错的”。

2.7.4 回归方程的应用与注意事项

  • 可用于预测：代入 X 值求 Ŷ
  • 可用于统计控制：通过控制 X 来限定 Y 的范围
  • 不要外推：预测时 X 不能超出建立方程时的取值范围
  • 相关 ≠ 因果：相关有统计学意义不等同于有因果关系

2.8 研究设计

【考试定位】约 2~3 分的选择题，考点集中在三要素和四原则。

2.8.1 研究类型

类型特征常见方法
观察性研究不施加干预，被动观察横断面研究、病例-对照研究、队列研究
实验性研究主动施加干预动物实验、临床试验、社区干预试验

2.8.2 实验设计的三要素

要素含义
受试对象研究对象（人/动物/标本），需有纳入和排除标准
处理因素研究者施加的干预措施
实验效应处理因素作用于受试对象产生的效果（用指标衡量）

2.8.3 实验设计的四原则

原则含义
随机化随机分配受试对象到各组，保证组间均衡可比
对照设立对照组，排除非处理因素影响（如空白对照、安慰剂对照等）
重复足够的样本量，保证结果可重复和统计推断的可靠性
盲法单盲/双盲/三盲，减少主观偏倚

2.8.4 常用抽样方法

方法特点
单纯随机抽样最基础，每个个体等概率被抽中
系统抽样按一定间隔抽取
分层抽样先分层再在各层内随机抽样
整群抽样以群体为单位抽取
多阶段抽样多个阶段、多种方法组合

三、考试策略与常见陷阱汇总

3.1 题型与分值分布

题型分值估计内容范围
选择题~70 分全书知识点，含送分题约 60%~70%
计算题（3 道）~30 分大概率：t 检验 1 道 + 秩和检验 1 道 + 卡方检验 1 道

3.2 计算题答题要点

  1. 判断资料类型和设计类型（计量/计数？正态/偏态？配对/独立？）
  2. 选择合适的检验方法，写清楚选择依据
  3. 写出 H₀ 和 H₁，确定 α = 0.05
  4. 写公式、代入数据（计算量大的题老师会给检验统计量的值）
  5. 查表得 P 值，作出结论

3.3 十大常见陷阱

#陷阱正确做法
1看到极端值还用均数偏态 → 中位数
2μ 到 μ+1.96σ 面积 = 95%应该是 47.5%
3率和构成比混淆率需要正确的分母（可能发生该现象的总数）
4置信区间公式用 S 而非 S_X̄X̄ ± t × S_X̄（标准误不是标准差）
5配对设计误用独立样本 t 检验看是否有”配成对子”或”同体前后”提示
6方差不齐还用 t 检验用 t’ 检验或秩和检验
7多组比较用多次 t 检验用方差分析 + 多重比较
8四格表把合计当成 B仔细区分 a、b、c、d 各自位置
9等级资料用卡方检验等级资料用秩和检验
10忘记校正条件n≥40 且 1≤T<5 → 校正；n<40 或 T<1 → Fisher

3.4 学习方法建议

  • 不要背题：统计学变个数答案就不同，必须理解每个知识点的原理
  • 理清逻辑链：资料类型 → 设计类型 → 分布特征 → 选择方法 → 写公式 → 做结论
  • 关注教材例题：类型会考，但原题不一定出，重点是掌握解题思路
